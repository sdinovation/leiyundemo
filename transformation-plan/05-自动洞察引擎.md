# 05 - 自动洞察引擎

> 本文档面向 AI 开发者，详细描述"数分精灵"项目自动洞察引擎模块的完整设计与实现。本模块解决当前工具"只出图、不解读"的核心瓶颈（00 文档瓶颈 6），将数据洞察生成从前端被动 LLM 解读升级为后端"规则引擎 + LLM 增强"双层架构。规则引擎层基于 Pandas 统计分析，毫秒级自动识别排名、趋势、异常值、相关性等数据特征，生成结构化洞察；LLM 增强层将统计结果交给 LLM 生成通俗易懂的自然语言解读。改造后工具从"出图工具"升级为"分析助手"。所有代码均为可直接运行的完整 Python 实现。

---

## 1. 模块概述

### 1.1 解决的问题

当前项目（`index.html`）虽已有 `llmDeepInterpretation(question, analysis, dataProfile)`（行 4494）和 `enrichInterpretationWithLLM(question, analysis)`（行 4556）两个解读函数，但存在以下局限：

| 局限 | 现状 | 影响 |
|------|------|------|
| **被动解读** | 仅在查询返回结果后生成 2-4 句简短文字，不会主动扫描数据 | 用户得到图表后仍需自行发现异常、趋势 |
| **依赖前端 LLM** | `llmDeepInterpretation` 必须有用户 API Key（`getApiKeyConfig()` 返回非 null），否则返回 `null` | 无 Key 用户完全没有解读 |
| **无结构化洞察** | 解读是 LLM 自由生成的文本，无类型分类、无关键发现提取 | 前端无法做结构化展示（卡片、标注） |
| **无异常检测** | 不会自动检测异常值、离群点 | 数据质量问题被忽略 |
| **无行动建议** | `recommendation` 意图仅走 LLM 文本回复，缺乏数据支撑 | 建议空洞、无具体数字 |
| **无数据集整体洞察** | 仅针对单次查询结果，无法对整个数据集做概况分析 | 用户上传数据后缺乏全局认知 |

### 1.2 改造方案

采用**双层洞察架构**，将洞察生成从"前端 LLM 被动解读"升级为"后端规则引擎 + LLM 增强"：

```
查询结果 DataFrame
       │
       ▼
┌──────────────────────────────────────┐
│  第一层：规则引擎 (InsightGenerator)   │  ← Pandas 统计分析，毫秒级
│                                      │
│  • 统计摘要  • 排名分析  • 趋势分析    │
│  • 占比分析  • 异常检测  • 对比分析    │
│  • 相关性    • 建议生成               │
│                                      │
│  输出：结构化洞察 JSON               │
│  { summary, insights[],              │
│    key_findings[], suggestions[] }   │
└──────────────┬───────────────────────┘
               │
               ▼
┌──────────────────────────────────────┐
│  第二层：LLM 增强 (InsightLLMEnhancer)│  ← 可选，深度解读
│                                      │
│  将结构化洞察 + 原始数据摘要          │
│  交给 LLM 生成 2-3 段自然语言解读     │
│                                      │
│  输出：通俗的自然语言洞察文本         │
└──────────────────────────────────────┘
```

**两层架构的设计考量**：

- **规则引擎层始终执行**：无论是否有 LLM，用户都能获得结构化洞察（排名、趋势、异常等）。这解决了"无 API Key 用户完全没有解读"的问题。
- **LLM 增强层可选执行**：有 LLM 时，将规则引擎的结构化结果作为事实基础交给 LLM，避免 LLM 幻觉（前端 `llmDeepInterpretation` 的防幻觉约束"严禁编造结果中不存在的数据"在规则引擎层天然满足）。
- **分层降低 LLM 成本**：规则引擎处理确定性分析（统计、排名），LLM 只负责语言润色和原因推测，Prompt 更短、Token 更省。

### 1.3 预期效果

| 指标 | 改造前（前端 LLM 解读） | 改造后（双层洞察引擎） |
|------|------------------------|----------------------|
| **洞察覆盖率** | 仅限有 API Key 用户，且仅查询后被动生成 | 100% 覆盖（规则引擎无需 Key） |
| **洞察类型** | LLM 自由生成文本，无分类 | 8 种结构化洞察类型 + LLM 自然语言增强 |
| **异常检测** | 无 | 2σ 规则自动检测，高亮标注 |
| **响应时间** | 3-8 秒（LLM 调用） | < 50ms（规则引擎）/ 1-3 秒（+ LLM 增强） |
| **行动建议** | 无数据支撑的文本建议 | 基于统计结果的具体建议（如"排名最低的西湖店建议关注"） |
| **数据集整体洞察** | 无 | 数据概况 + 字段统计 + 质量评估 + 探索方向 |

## 2. 洞察类型定义

系统支持 8 种洞察类型，按触发条件自动激活。每种洞察类型对应规则引擎中的一个分析方法：

| 洞察类型 | 触发条件 | 分析方法 | 示例输出 |
|---------|---------|---------|---------|
| **统计摘要** | 所有数值字段 | `_summarize_numeric` | "日营业额：总计1,234,567元，平均3,456元/天，最高8,900元，最低1,200元" |
| **排名分析** | bar 图，多组数据（≥2 行） | `_ranking_analysis` | "排名最高：外滩店（日营业额8,900元），最低：西湖店（3,200元），差距5,700元" |
| **趋势分析** | line 图，时间序列（≥2 行） | `_trend_analysis` | "日营业额整体呈上升趋势，从1月的3,200元增长到6月的8,900元，增幅178%" |
| **占比分析** | pie 图 | `_distribution_analysis` | "主食类占比最高（35%），其次为汤品（25%），甜品占比最低（15%）" |
| **异常检测** | 数值字段，≥4 个数据点 | `_anomaly_detection` | "检测到2月15日日营业额存在异常值（12,000元，偏离均值3.2个标准差）" |
| **对比分析** | comparison 意图 | `_comparison_analysis` | "外滩店日营业额（8,900元）显著高于西湖店（3,200元），差距为2.78倍" |
| **相关性** | scatter 图，≥2 个数值列 | `_correlation_analysis` | "日销量与日营业额呈强正相关（r=0.95），表明销量是营业额的主要驱动因素" |
| **数据质量** | 所有数据 | `_data_quality_check` | "数据共365行，无缺失值，字段类型推断准确率100%" |
| **建议生成** | 基于以上分析结果 | `_generate_suggestions` | "西湖店日营业额排名最低，建议分析原因并制定提升方案" |

### 2.1 洞察分发逻辑

`InsightGenerator.generate()` 根据图表类型和查询意图，自动分发到对应的分析方法：

| 图表类型 | 查询意图 | 激活的洞察类型 |
|---------|---------|--------------|
| `bar` | `ranking` | 统计摘要 + 排名分析 + 异常检测 + 建议 |
| `bar` | `comparison` | 统计摘要 + 对比分析 + 建议 |
| `line` | `trend` | 统计摘要 + 趋势分析 + 异常检测 + 建议 |
| `pie` | `distribution` | 占比分析 + 建议 |
| `scatter` | `correlation` | 相关性分析 + 建议 |
| `number` | `summary` / `scalar` | 统计摘要 |
| `table` | `list` / `filter` | 统计摘要 + 数据质量 |
| 任意 | 任意 | 数据质量（始终执行） |

## 3. 规则引擎实现 (core/insight_generator.py)

### 3.1 配置依赖

在 `config.py` 中新增 `INSIGHT_CONFIG` 配置段（追加到 02 文档已有的配置之后）：

```python
# ============================================================
# 洞察引擎配置
# ============================================================

INSIGHT_CONFIG = {
    # 异常检测：偏离均值的标准差倍数阈值
    # 超过此阈值视为异常值（经验值：2σ 覆盖 95% 数据，3σ 覆盖 99.7%）
    'anomaly_sigma_threshold': 2.0,
    # 异常检测：最少数据点数，少于此数不执行异常检测
    # （数据太少时标准差无统计意义）
    'anomaly_min_points': 4,
    # 相关性分析：强相关阈值（|r| > 此值视为强相关）
    'correlation_strong_threshold': 0.7,
    # 相关性分析：弱相关阈值（|r| < 此值视为弱相关）
    'correlation_weak_threshold': 0.3,
    # 占比分析：主导项阈值（单项占比超过此值视为主导）
    'distribution_dominant_threshold': 0.5,
    # 趋势分析：最小变化率（百分比），低于此值视为"基本平稳"
    'trend_min_change_rate': 5.0,
    # LLM 增强层：是否默认启用（可被请求参数覆盖）
    'llm_enhance_enabled': True,
    # LLM 增强层：最大输入数据行数（控制 Token 消耗）
    'llm_max_data_rows': 10,
}
```

### 3.2 完整的 InsightGenerator 类

创建 `core/insight_generator.py`：

```python
"""
core/insight_generator.py — 自动洞察生成引擎（规则引擎层）

基于 Pandas 统计分析，自动识别数据中的排名、趋势、异常值、相关性等特征，
生成结构化洞察。无需 LLM 调用，毫秒级响应。

对应前端：
- llmDeepInterpretation(question, analysis, dataProfile) [行4494] 的规则引擎替代
- enrichInterpretationWithLLM(question, analysis) [行4556] 的结构化基础

设计原则：
1. 规则引擎层始终执行，不依赖 LLM 或 API Key
2. 所有洞察基于真实数据计算，杜绝幻觉
3. 输出结构化 JSON，前端可做卡片/标注等结构化展示
4. 支持 8 种洞察类型，按图表类型和意图自动分发
"""

import pandas as pd
import numpy as np
from typing import List, Dict, Any, Optional, Tuple
from config import INSIGHT_CONFIG


class InsightGenerator:
    """自动洞察生成引擎。

    使用方式：
        generator = InsightGenerator()
        result = generator.generate(df, question, chart_type, intent, columns)
        # result = {
        #     "summary": "一句话总结",
        #     "insights": ["洞察1", "洞察2", ...],
        #     "key_findings": [{"type": "ranking", "title": "...", "value": "..."}],
        #     "suggestions": ["建议1", "建议2"]
        # }

    依赖：
        - pandas（数据分析）
        - numpy（数值计算）
        - config.INSIGHT_CONFIG（阈值配置）
    """

    def __init__(self):
        self.config = INSIGHT_CONFIG

    # ============================================================
    # 主入口
    # ============================================================

    def generate(self, df: pd.DataFrame, question: str, chart_type: str,
                 intent: str, columns: List[str]) -> Dict[str, Any]:
        """生成完整的洞察结果。

        根据图表类型和查询意图，自动分发到对应的分析方法，
        汇总所有洞察为结构化结果。

        Args:
            df: 查询结果的 DataFrame
            question: 用户原始问题
            chart_type: 图表类型 (bar/line/pie/number/table/scatter)
            intent: 查询意图
                (ranking/trend/comparison/distribution/summary/list/correlation/filter)
            columns: 数据列名列表

        Returns:
            {
                "summary": "一句话总结",
                "insights": ["洞察1", "洞察2", ...],
                "key_findings": [{"type": "ranking", "title": "...", "value": "..."}],
                "suggestions": ["建议1", "建议2"]
            }
        """
        insights: List[str] = []
        key_findings: List[Dict[str, str]] = []

        # 空数据兜底
        if df is None or len(df) == 0:
            return {
                "summary": "查询结果为空，无法生成洞察。",
                "insights": ["当前查询条件下没有返回数据，建议调整筛选条件后重试。"],
                "key_findings": [],
                "suggestions": ["检查筛选条件是否过于严格", "尝试扩大时间范围或移除部分过滤条件"],
            }

        # 识别数值列和维度列
        numeric_cols = self._get_numeric_columns(df)
        dimension_cols = self._get_dimension_columns(df, numeric_cols)

        # 1. 统计摘要（所有数值字段始终执行）
        for col in numeric_cols:
            summary_text = self._summarize_numeric(df, col)
            if summary_text:
                insights.append(summary_text)
                key_findings.append({
                    "type": "summary",
                    "title": f"{col} 统计摘要",
                    "value": summary_text,
                })

        # 2. 按图表类型和意图分发专项分析
        chart_type = (chart_type or '').lower()
        intent = (intent or '').lower()

        if chart_type == 'bar':
            if intent == 'comparison':
                comp_text, comp_finding = self._comparison_analysis(df)
                if comp_text:
                    insights.append(comp_text)
                    key_findings.append(comp_finding)
            else:
                # ranking 或默认走排名分析
                rank_text, rank_finding = self._ranking_analysis(df, chart_type)
                if rank_text:
                    insights.append(rank_text)
                    key_findings.append(rank_finding)

        elif chart_type == 'line':
            trend_text, trend_finding = self._trend_analysis(df)
            if trend_text:
                insights.append(trend_text)
                key_findings.append(trend_finding)

        elif chart_type == 'pie':
            dist_text, dist_finding = self._distribution_analysis(df)
            if dist_text:
                insights.append(dist_text)
                key_findings.append(dist_finding)

        elif chart_type == 'scatter':
            corr_text, corr_finding = self._correlation_analysis(df)
            if corr_text:
                insights.append(corr_text)
                key_findings.append(corr_finding)

        elif chart_type == 'number':
            # number 类型已在统计摘要中覆盖，无需额外分析
            pass

        # 3. 异常检测（所有数值字段，满足条件时执行）
        anomaly_texts = self._anomaly_detection(df)
        for text in anomaly_texts:
            insights.append(text)
            key_findings.append({
                "type": "anomaly",
                "title": "异常值检测",
                "value": text,
            })

        # 4. 数据质量检查（始终执行）
        quality_text = self._data_quality_check(df)
        if quality_text:
            insights.append(quality_text)
            key_findings.append({
                "type": "quality",
                "title": "数据质量",
                "value": quality_text,
            })

        # 5. 生成行动建议
        suggestions = self._generate_suggestions(df, intent, insights)

        # 6. 生成一句话总结
        summary = self._build_summary(df, question, chart_type, intent, key_findings)

        return {
            "summary": summary,
            "insights": insights,
            "key_findings": key_findings,
            "suggestions": suggestions,
        }

    # ============================================================
    # 辅助方法：列类型识别
    # ============================================================

    def _get_numeric_columns(self, df: pd.DataFrame) -> List[str]:
        """识别 DataFrame 中的数值列。

        尝试将每列转换为数值类型，成功且非全空的列视为数值列。
        同时过滤掉唯一值过少的列（如布尔型 0/1），除非列名含"率"等百分比语义。

        Args:
            df: 输入 DataFrame

        Returns:
            数值列名列表
        """
        numeric_cols = []
        for col in df.columns:
            # 尝试转换为数值
            converted = pd.to_numeric(df[col], errors='coerce')
            # 非空数值占比超过 80% 视为数值列
            non_null_ratio = converted.notna().sum() / max(len(df), 1)
            if non_null_ratio >= 0.8:
                numeric_cols.append(col)
        return numeric_cols

    def _get_dimension_columns(self, df: pd.DataFrame,
                               numeric_cols: List[str]) -> List[str]:
        """识别维度列（非数值列，如门店名称、日期、类别等）。

        Args:
            df: 输入 DataFrame
            numeric_cols: 已识别的数值列名列表

        Returns:
            维度列名列表
        """
        return [col for col in df.columns if col not in numeric_cols]

    def _format_number(self, value: float, suffix: str = '') -> str:
        """格式化数字，大数自动加万/亿单位，保留合理小数位。

        Args:
            value: 数值
            suffix: 单位后缀（如"元"、"份"）

        Returns:
            格式化后的字符串，如 "12,345.6元" 或 "1.2万元"
        """
        if value is None or (isinstance(value, float) and np.isnan(value)):
            return 'N/A'

        abs_val = abs(value)

        if abs_val >= 1e8:
            return f'{value / 1e8:.2f}亿{suffix}'
        elif abs_val >= 1e4:
            return f'{value / 1e4:.2f}万{suffix}'
        elif abs_val == int(abs_val):
            return f'{int(value):,}{suffix}'
        else:
            return f'{value:,.2f}{suffix}'

    # ============================================================
    # 3.1 统计摘要
    # ============================================================

    def _summarize_numeric(self, df: pd.DataFrame, col: str) -> str:
        """数值字段统计摘要：总和、平均、最大、最小、中位数、标准差。

        对应前端 llmDeepInterpretation [行4508-4521] 中的数值统计逻辑，
        但增加了中位数和标准差，输出更完整的统计摘要。

        Args:
            df: 输入 DataFrame
            col: 数值列名

        Returns:
            格式化的统计摘要字符串，如：
            "日营业额(元)：总计1,234,567元，平均3,456元，最高8,900元，最低1,200元，中位数3,200元，标准差1,500元"
            无有效数据时返回空字符串。
        """
        values = pd.to_numeric(df[col], errors='coerce').dropna()
        if len(values) == 0:
            return ''

        total = float(values.sum())
        avg = float(values.mean())
        maximum = float(values.max())
        minimum = float(values.min())
        median = float(values.median())
        std = float(values.std()) if len(values) > 1 else 0.0

        # 判断单位后缀（从列名推断）
        suffix = ''
        col_lower = col.lower()
        if any(kw in col for kw in ['营业额', '销售额', '收入', '成本', '金额', '价格', '单价']):
            suffix = '元'
        elif any(kw in col for kw in ['销量', '数量', '个数', '条数']):
            suffix = '份' if '销量' in col else '个'
        elif '%' in col or '率' in col:
            suffix = '%'

        summary = (
            f'{col}：总计{self._format_number(total, suffix)}，'
            f'平均{self._format_number(avg, suffix)}，'
            f'最高{self._format_number(maximum, suffix)}，'
            f'最低{self._format_number(minimum, suffix)}，'
            f'中位数{self._format_number(median, suffix)}，'
            f'标准差{self._format_number(std, suffix)}'
        )

        return summary

    # ============================================================
    # 3.2 排名分析
    # ============================================================

    def _ranking_analysis(self, df: pd.DataFrame,
                          chart_type: str) -> Tuple[str, Dict[str, str]]:
        """排名分析：最高、最低、差距、倍数。

        适用于 bar 图的 ranking 意图。找到数值列和维度列，
        找出最高和最低的维度项，计算差距和倍数。

        Args:
            df: 输入 DataFrame（查询结果，通常已聚合）
            chart_type: 图表类型

        Returns:
            (排名分析文本, 关键发现字典)
            如：
            ("排名最高：外滩店（日营业额8,900元），最低：西湖店（3,200元），差距5,700元，相差2.78倍",
             {"type": "ranking", "title": "排名分析", "value": "..."})
            无有效数据时返回 ("", {})。
        """
        if len(df) < 2:
            return '', {}

        numeric_cols = self._get_numeric_columns(df)
        dimension_cols = self._get_dimension_columns(df, numeric_cols)

        if not numeric_cols or not dimension_cols:
            return '', {}

        # 取第一个数值列作为指标，第一个维度列作为分组
        metric_col = numeric_cols[0]
        dim_col = dimension_cols[0]

        # 转换数值并排序
        df_sorted = df.copy()
        df_sorted[metric_col] = pd.to_numeric(df_sorted[metric_col], errors='coerce')
        df_sorted = df_sorted.dropna(subset=[metric_col]).sort_values(
            metric_col, ascending=False
        )

        if len(df_sorted) < 2:
            return '', {}

        top_row = df_sorted.iloc[0]
        bottom_row = df_sorted.iloc[-1]

        top_name = str(top_row[dim_col])
        top_value = float(top_row[metric_col])
        bottom_name = str(bottom_row[dim_col])
        bottom_value = float(bottom_row[dim_col])

        # 判断单位后缀
        suffix = ''
        if any(kw in metric_col for kw in ['营业额', '销售额', '收入', '成本', '金额', '价格', '单价']):
            suffix = '元'
        elif any(kw in metric_col for kw in ['销量', '数量']):
            suffix = '份'

        gap = top_value - bottom_value

        # 倍数关系（避免除以 0）
        if abs(bottom_value) > 0.001:
            multiple = top_value / bottom_value
            multiple_text = f'，相差{multiple:.2f}倍'
        else:
            multiple_text = ''

        text = (
            f'排名最高：{top_name}（{metric_col}{self._format_number(top_value, suffix)}），'
            f'最低：{bottom_name}（{self._format_number(bottom_value, suffix)}），'
            f'差距{self._format_number(gap, suffix)}{multiple_text}'
        )

        finding = {
            'type': 'ranking',
            'title': f'{metric_col}排名',
            'value': text,
        }

        return text, finding

    # ============================================================
    # 3.3 趋势分析
    # ============================================================

    def _trend_analysis(self, df: pd.DataFrame) -> Tuple[str, Dict[str, str]]:
        """趋势分析：整体方向、变化幅度、增长率、拐点检测。

        适用于 line 图的趋势分析。计算首尾值的变化，判断上升/下降/平稳，
        计算增长率百分比，并检测拐点（方向反转点）。

        Args:
            df: 输入 DataFrame（时间序列数据）

        Returns:
            (趋势分析文本, 关键发现字典)
            如：
            ("日营业额整体呈上升趋势，从1月的3,200元增长到6月的8,900元，增幅178%，检测到1个拐点",
             {"type": "trend", "title": "趋势分析", "value": "..."})
            无有效数据时返回 ("", {})。
        """
        if len(df) < 2:
            return '', {}

        numeric_cols = self._get_numeric_columns(df)
        if not numeric_cols:
            return '', {}

        metric_col = numeric_cols[0]
        values = pd.to_numeric(df[metric_col], errors='coerce').dropna()

        if len(values) < 2:
            return '', {}

        first_val = float(values.iloc[0])
        last_val = float(values.iloc[-1])

        # 判断单位后缀
        suffix = ''
        if any(kw in metric_col for kw in ['营业额', '销售额', '收入', '成本', '金额']):
            suffix = '元'
        elif any(kw in metric_col for kw in ['销量', '数量']):
            suffix = '份'

        # 计算变化率和增长率
        change = last_val - first_val
        if abs(first_val) > 0.001:
            growth_rate = (change / abs(first_val)) * 100
        else:
            growth_rate = 0.0

        # 判断趋势方向
        min_change = self.config['trend_min_change_rate']
        if abs(growth_rate) < min_change:
            direction = '基本平稳'
            change_text = f'变化幅度仅{growth_rate:+.1f}%'
        elif change > 0:
            direction = '上升'
            change_text = f'增幅{growth_rate:.1f}%'
        else:
            direction = '下降'
            change_text = f'降幅{abs(growth_rate):.1f}%'

        # 检测拐点（方向反转）
        inflection_points = self._detect_inflection_points(values)

        # 获取首尾的标签（如果有维度列）
        dimension_cols = self._get_dimension_columns(df, numeric_cols)
        first_label = str(df.iloc[0][dimension_cols[0]]) if dimension_cols else f'第1期'
        last_label = str(df.iloc[-1][dimension_cols[0]]) if dimension_cols else f'第{len(df)}期'

        text = (
            f'{metric_col}整体呈{direction}趋势，'
            f'从{first_label}的{self._format_number(first_val, suffix)}'
            f'{"增长" if change > 0 else ("减少" if change < 0 else "变化")}到'
            f'{last_label}的{self._format_number(last_val, suffix)}，'
            f'{change_text}'
        )

        if inflection_points > 0:
            text += f'，检测到{inflection_points}个拐点'

        finding = {
            'type': 'trend',
            'title': f'{metric_col}趋势',
            'value': text,
        }

        return text, finding

    def _detect_inflection_points(self, values: pd.Series) -> int:
        """检测时间序列的拐点（方向反转点）。

        拐点定义：相邻两期的变化方向发生反转（从上升变下降，或反之）。

        Args:
            values: 数值序列

        Returns:
            拐点数量
        """
        if len(values) < 3:
            return 0

        diffs = values.diff().dropna()
        # 方向：1=上升，-1=下降，0=持平
        directions = np.sign(diffs.values)
        inflection_count = 0
        prev_dir = 0

        for d in directions:
            if d != 0:
                if prev_dir != 0 and d != prev_dir:
                    inflection_count += 1
                prev_dir = d

        return inflection_count

    # ============================================================
    # 3.4 占比分析
    # ============================================================

    def _distribution_analysis(self, df: pd.DataFrame) -> Tuple[str, Dict[str, str]]:
        """占比分析：最高占比、最低占比、集中度。

        适用于 pie 图的分布/占比分析。计算各项占总和的比例，
        识别主导项，计算集中度（Top3 占比之和）。

        Args:
            df: 输入 DataFrame

        Returns:
            (占比分析文本, 关键发现字典)
            如：
            ("主食类占比最高（35.0%），其次为汤品（25.0%），甜品占比最低（15.0%），Top3合计占比75.0%",
             {"type": "distribution", "title": "占比分析", "value": "..."})
            无有效数据时返回 ("", {})。
        """
        if len(df) < 2:
            return '', {}

        numeric_cols = self._get_numeric_columns(df)
        dimension_cols = self._get_dimension_columns(df, numeric_cols)

        if not numeric_cols or not dimension_cols:
            return '', {}

        metric_col = numeric_cols[0]
        dim_col = dimension_cols[0]

        df_calc = df.copy()
        df_calc[metric_col] = pd.to_numeric(df_calc[metric_col], errors='coerce')
        df_calc = df_calc.dropna(subset=[metric_col])

        if len(df_calc) < 2:
            return '', {}

        total = float(df_calc[metric_col].sum())
        if abs(total) < 0.001:
            return '', {}

        # 计算各项占比并排序
        df_calc['占比'] = df_calc[metric_col] / total
        df_calc = df_calc.sort_values('占比', ascending=False)

        top_item = df_calc.iloc[0]
        second_item = df_calc.iloc[1] if len(df_calc) > 1 else None
        bottom_item = df_calc.iloc[-1]

        top_name = str(top_item[dim_col])
        top_pct = float(top_item['占比']) * 100
        bottom_name = str(bottom_item[dim_col])
        bottom_pct = float(bottom_item['占比']) * 100

        # Top3 集中度
        top3_pct = float(df_calc['占比'].head(3).sum()) * 100

        # 主导项判断
        dominant_threshold = self.config['distribution_dominant_threshold']
        is_dominant = float(top_item['占比']) >= dominant_threshold

        parts = [
            f'{top_name}占比最高（{top_pct:.1f}%）',
        ]

        if second_item is not None:
            second_name = str(second_item[dim_col])
            second_pct = float(second_item['占比']) * 100
            parts.append(f'其次为{second_name}（{second_pct:.1f}%）')

        parts.append(f'{bottom_name}占比最低（{bottom_pct:.1f}%）')
        parts.append(f'Top3合计占比{top3_pct:.1f}%')

        if is_dominant:
            parts.append(f'{top_name}占据主导地位')

        text = '，'.join(parts)

        finding = {
            'type': 'distribution',
            'title': f'{dim_col}占比分布',
            'value': text,
        }

        return text, finding

    # ============================================================
    # 3.5 异常检测
    # ============================================================

    def _anomaly_detection(self, df: pd.DataFrame) -> List[str]:
        """异常值检测：2σ规则。

        对每个数值列，计算均值和标准差，找出偏离均值超过 N 个标准差的数据点。
        N 由 INSIGHT_CONFIG['anomaly_sigma_threshold'] 配置，默认 2.0。

        Args:
            df: 输入 DataFrame

        Returns:
            异常值描述列表，每条描述一个异常点，如：
            ["检测到2024-01-15的日营业额存在异常值（12,000元，偏离均值3.2个标准差）"]
            无异常时返回空列表。
        """
        min_points = self.config['anomaly_min_points']
        sigma_threshold = self.config['anomaly_sigma_threshold']

        results: List[str] = []
        numeric_cols = self._get_numeric_columns(df)
        dimension_cols = self._get_dimension_columns(df, numeric_cols)

        for col in numeric_cols:
            values = pd.to_numeric(df[col], errors='coerce')
            valid_values = values.dropna()

            # 数据点不足，跳过
            if len(valid_values) < min_points:
                continue

            mean_val = float(valid_values.mean())
            std_val = float(valid_values.std())

            # 标准差为 0（所有值相同），无法检测异常
            if std_val < 0.001:
                continue

            # 计算 Z-Score
            z_scores = (values - mean_val) / std_val

            # 找出异常点
            anomaly_mask = z_scores.abs() >= sigma_threshold
            anomaly_indices = df[anomaly_mask.fillna(False)].index

            if len(anomaly_indices) == 0:
                continue

            # 判断单位后缀
            suffix = ''
            if any(kw in col for kw in ['营业额', '销售额', '收入', '成本', '金额']):
                suffix = '元'
            elif any(kw in col for kw in ['销量', '数量']):
                suffix = '份'

            for idx in anomaly_indices:
                row = df.loc[idx]
                anomaly_value = float(values.loc[idx])
                z_score = float(z_scores.loc[idx])
                direction = '偏高' if z_score > 0 else '偏低'

                # 尝试获取维度标签（如日期、门店名）用于定位
                label_parts = []
                for dim_col in dimension_cols[:2]:  # 最多取 2 个维度定位
                    label_parts.append(str(row[dim_col]))
                label = '·'.join(label_parts) if label_parts else f'第{idx + 1}行'

                text = (
                    f'检测到{label}的{col}存在异常值'
                    f'（{self._format_number(anomaly_value, suffix)}，'
                    f'{direction}，偏离均值{abs(z_score):.1f}个标准差）'
                )
                results.append(text)

        return results

    # ============================================================
    # 3.6 对比分析
    # ============================================================

    def _comparison_analysis(self, df: pd.DataFrame) -> Tuple[str, Dict[str, str]]:
        """对比分析：组间差异、倍数关系。

        适用于 comparison 意图的 bar 图。比较各组的数值差异，
        计算最大差异和倍数关系。

        Args:
            df: 输入 DataFrame

        Returns:
            (对比分析文本, 关键发现字典)
            如：
            ("外滩店日营业额（8,900元）显著高于西湖店（3,200元），差距为5,700元，约2.78倍",
             {"type": "comparison", "title": "对比分析", "value": "..."})
            无有效数据时返回 ("", {})。
        """
        if len(df) < 2:
            return '', {}

        numeric_cols = self._get_numeric_columns(df)
        dimension_cols = self._get_dimension_columns(df, numeric_cols)

        if not numeric_cols or not dimension_cols:
            return '', {}

        metric_col = numeric_cols[0]
        dim_col = dimension_cols[0]

        df_calc = df.copy()
        df_calc[metric_col] = pd.to_numeric(df_calc[metric_col], errors='coerce')
        df_calc = df_calc.dropna(subset=[metric_col])

        if len(df_calc) < 2:
            return '', {}

        df_sorted = df_calc.sort_values(metric_col, ascending=False)
        highest = df_sorted.iloc[0]
        lowest = df_sorted.iloc[-1]

        high_name = str(highest[dim_col])
        high_val = float(highest[metric_col])
        low_name = str(lowest[dim_col])
        low_val = float(lowest[metric_col])

        # 判断单位后缀
        suffix = ''
        if any(kw in metric_col for kw in ['营业额', '销售额', '收入', '成本', '金额']):
            suffix = '元'
        elif any(kw in metric_col for kw in ['销量', '数量']):
            suffix = '份'

        diff = high_val - low_val

        # 显著性判断
        if abs(low_val) > 0.001:
            multiple = high_val / low_val
            if multiple >= 3:
                significance = '显著高于'
            elif multiple >= 1.5:
                significance = '明显高于'
            else:
                significance = '略高于'
            multiple_text = f'，约{multiple:.2f}倍'
        else:
            significance = '高于'
            multiple_text = ''

        text = (
            f'{high_name}{metric_col}（{self._format_number(high_val, suffix)}）'
            f'{significance}{low_name}（{self._format_number(low_val, suffix)}），'
            f'差距为{self._format_number(diff, suffix)}{multiple_text}'
        )

        finding = {
            'type': 'comparison',
            'title': f'{metric_col}对比',
            'value': text,
        }

        return text, finding

    # ============================================================
    # 3.7 相关性分析
    # ============================================================

    def _correlation_analysis(self, df: pd.DataFrame) -> Tuple[str, Dict[str, str]]:
        """相关性分析：皮尔逊相关系数。

        适用于 scatter 图的相关性分析。计算数值列间的皮尔逊相关系数矩阵，
        识别强相关（|r| > 0.7）和弱相关（|r| < 0.3），
        返回最显著的相关性描述。

        Args:
            df: 输入 DataFrame

        Returns:
            (相关性分析文本, 关键发现字典)
            如：
            ("日销量与日营业额呈强正相关（r=0.95），表明销量是营业额的主要驱动因素",
             {"type": "correlation", "title": "相关性分析", "value": "..."})
            无有效数据时返回 ("", {})。
        """
        numeric_cols = self._get_numeric_columns(df)

        # 散点图至少需要 2 个数值列
        if len(numeric_cols) < 2:
            return '', {}

        # 构建数值矩阵
        numeric_df = df[numeric_cols].apply(pd.to_numeric, errors='coerce').dropna()

        if len(numeric_df) < 3:
            return '', {}

        # 计算相关系数矩阵
        corr_matrix = numeric_df.corr(method='pearson')

        strong_threshold = self.config['correlation_strong_threshold']
        weak_threshold = self.config['correlation_weak_threshold']

        # 找出最强的相关性对（排除自相关）
        strongest_pair = None
        strongest_abs_r = 0

        for i in range(len(numeric_cols)):
            for j in range(i + 1, len(numeric_cols)):
                col_a = numeric_cols[i]
                col_b = numeric_cols[j]
                r = float(corr_matrix.loc[col_a, col_b])

                if np.isnan(r):
                    continue

                if abs(r) > strongest_abs_r:
                    strongest_abs_r = abs(r)
                    strongest_pair = (col_a, col_b, r)

        if strongest_pair is None:
            return '', {}

        col_a, col_b, r = strongest_pair

        # 判断相关性强度和方向
        abs_r = abs(r)
        if abs_r >= strong_threshold:
            strength = '强'
        elif abs_r >= weak_threshold:
            strength = '中等'
        else:
            strength = '弱'

        direction = '正相' if r > 0 else '负相'

        if abs_r < weak_threshold:
            # 弱相关，说明两者关系不大
            text = (
                f'{col_a}与{col_b}相关性较弱（r={r:.2f}），'
                f'表明两者之间没有明显的线性关系'
            )
        else:
            text = (
                f'{col_a}与{col_b}呈{strength}{direction}关（r={r:.2f}），'
            )
            if r > 0:
                text += f'表明{col_a}越高，{col_b}也越高'
            else:
                text += f'表明{col_a}越高，{col_b}反而越低'

        finding = {
            'type': 'correlation',
            'title': '相关性分析',
            'value': text,
        }

        return text, finding

    # ============================================================
    # 3.8 建议生成
    # ============================================================

    def _generate_suggestions(self, df: pd.DataFrame, intent: str,
                              insights: List[str]) -> List[str]:
        """基于分析结果生成行动建议。

        根据洞察类型和内容，生成具体的、有数据支撑的行动建议。
        建议不是空洞的"请关注"，而是指向具体的维度和数值。

        Args:
            df: 输入 DataFrame
            intent: 查询意图
            insights: 已生成的洞察文本列表

        Returns:
            建议列表，如：
            ["西湖店日营业额排名最低，建议分析原因并制定提升方案",
             "检测到异常值，建议核实数据来源是否准确"]
        """
        suggestions: List[str] = []

        if not insights:
            return suggestions

        # 合并所有洞察文本用于模式匹配
        all_text = ' '.join(insights)

        # 1. 排名最低建议
        if '排名' in all_text or '最低' in all_text:
            # 提取排名最低的项
            for insight in insights:
                if '最低' in insight and '排名' in insight:
                    # 尝试提取最低项名称
                    parts = insight.split('最低')
                    if len(parts) >= 2:
                        low_part = parts[1]
                        # 提取名称（在"："或"："之后，"（"之前）
                        for sep in ['：', ':']:
                            if sep in low_part:
                                name_candidate = low_part.split(sep)[-1]
                                if '（' in name_candidate:
                                    name = name_candidate.split('（')[0].strip()
                                    if name and len(name) < 20:
                                        suggestions.append(
                                            f'{name}排名最低，建议分析原因并制定提升方案'
                                        )
                                break
                    break

        # 2. 下降趋势建议
        if '下降' in all_text or '降幅' in all_text:
            suggestions.append('数据呈下降趋势，建议深入分析下降原因，关注关键影响因素')

        # 3. 异常值建议
        if '异常' in all_text:
            suggestions.append('检测到异常值，建议核实数据来源是否准确，排查是否有特殊情况')

        # 4. 主导项建议
        if '主导' in all_text:
            suggestions.append('存在明显的主导项，建议关注其可持续性，同时挖掘其他项的增长潜力')

        # 5. 强相关建议
        if '强正相' in all_text:
            suggestions.append('发现强正相关关系，可利用此关系进行预测和协同优化')
        elif '强负相' in all_text:
            suggestions.append('发现强负相关关系，需注意两者的此消彼长效应，平衡资源配置')

        # 6. 差距过大建议
        if '倍' in all_text and ('显著高于' in all_text or '明显高于' in all_text):
            suggestions.append('组间差距较大，建议对标最高水平，找出可复制的成功因素')

        # 7. 数据质量建议
        if '缺失值' in all_text and '无缺失值' not in all_text:
            suggestions.append('数据存在缺失值，建议补全数据或在分析时注明数据完整度')

        # 8. 通用建议（如果以上都没命中）
        if not suggestions:
            numeric_cols = self._get_numeric_columns(df)
            dimension_cols = self._get_dimension_columns(df, numeric_cols)
            if dimension_cols and numeric_cols:
                suggestions.append(
                    f'建议进一步按{dimension_cols[0]}分组分析{numeric_cols[0]}，挖掘更细粒度的洞察'
                )
            else:
                suggestions.append('建议结合业务背景进一步解读数据，探索潜在的分析方向')

        # 去重（保持顺序）
        seen = set()
        unique_suggestions = []
        for s in suggestions:
            if s not in seen:
                seen.add(s)
                unique_suggestions.append(s)

        return unique_suggestions

    # ============================================================
    # 数据质量检查
    # ============================================================

    def _data_quality_check(self, df: pd.DataFrame) -> str:
        """数据质量检查：行数、缺失率、字段类型。

        检查数据的完整性，包括总行数、缺失值情况、列数，
        给出数据质量的整体评估。

        Args:
            df: 输入 DataFrame

        Returns:
            数据质量描述字符串，如：
            "数据共365行12列，无缺失值，数据完整性良好"
        """
        total_rows = len(df)
        total_cols = len(df.columns)

        # 缺失值统计
        missing_count = int(df.isnull().sum().sum())
        total_cells = total_rows * total_cols
        missing_rate = (missing_count / total_cells * 100) if total_cells > 0 else 0

        # 数值列和维度列统计
        numeric_cols = self._get_numeric_columns(df)
        dimension_cols = self._get_dimension_columns(df, numeric_cols)

        parts = [
            f'数据共{total_rows}行{total_cols}列',
            f'（数值字段{len(numeric_cols)}个，维度字段{len(dimension_cols)}个）',
        ]

        if missing_count == 0:
            parts.append('无缺失值，数据完整性良好')
        else:
            parts.append(f'存在{missing_count}个缺失值（缺失率{missing_rate:.1f}%）')

        # 检测重复行
        dup_count = int(df.duplicated().sum())
        if dup_count > 0:
            parts.append(f'，有{dup_count}行重复数据')

        return '，'.join(parts)

    # ============================================================
    # 一句话总结生成
    # ============================================================

    def _build_summary(self, df: pd.DataFrame, question: str,
                       chart_type: str, intent: str,
                       key_findings: List[Dict[str, str]]) -> str:
        """基于关键发现生成一句话总结。

        从关键发现中提取最重要的 1-2 个信息，组合成一句话总结。
        优先级：异常 > 排名/对比 > 趋势 > 占比 > 统计摘要 > 质量。

        Args:
            df: 输入 DataFrame
            question: 用户原始问题
            chart_type: 图表类型
            intent: 查询意图
            key_findings: 关键发现列表

        Returns:
            一句话总结字符串
        """
        if not key_findings:
            return f'共返回{len(df)}行数据，请查看图表了解详情。'

        # 按优先级提取关键发现
        priority_order = ['anomaly', 'ranking', 'comparison', 'trend',
                          'distribution', 'correlation', 'summary', 'quality']
        findings_by_type = {}
        for finding in key_findings:
            ftype = finding.get('type', '')
            if ftype not in findings_by_type:
                findings_by_type[ftype] = finding

        # 找到最高优先级的核心发现
        core_finding = None
        for ftype in priority_order:
            if ftype in findings_by_type:
                core_finding = findings_by_type[ftype]
                break

        if core_finding is None:
            core_finding = key_findings[0]

        # 提取核心发现的 value 并截断
        core_value = core_finding.get('value', '')
        # 截断到 100 字以内
        if len(core_value) > 100:
            core_value = core_value[:97] + '...'

        return core_value
```

## 4. LLM 增强洞察 (core/insight_llm.py)

### 4.1 设计思路

规则引擎生成的是结构化洞察（`"排名最高：外滩店（8,900元）..."`），语言风格偏机械。LLM 增强层将这些结构化结果作为**事实基础**交给 LLM，让它用通俗易懂的语言重新组织，加入原因推测和行动建议。

**防幻觉设计**（对齐前端 `llmDeepInterpretation` 行 4524 的"严禁编造结果中不存在的数据"约束）：
- Prompt 中明确要求"只能基于给定的结构化分析结果进行解读"
- 提供原始数据摘要（前 10 行）供 LLM 参考具体数字
- 禁止 LLM 引入结构化结果中未提及的字段名或数值

### 4.2 完整的 InsightLLMEnhancer 类

创建 `core/insight_llm.py`：

```python
"""
core/insight_llm.py — LLM 洞察增强层

将规则引擎生成的结构化洞察交给 LLM，生成通俗易懂的自然语言解读。
规则引擎提供事实基础（统计结果），LLM 负责语言润色和原因推测，
分层设计天然防止 LLM 幻觉。

对应前端：
- llmDeepInterpretation(question, analysis, dataProfile) [行4494] 的后端增强版
- enrichInterpretationWithLLM(question, analysis) [行4556] 的深度版

依赖：
- utils/llm_client.py 的 LLMClient（03 文档已实现）
- config.py 的 LLM_CONFIG 和 INSIGHT_CONFIG
"""

import json
import logging
from typing import Dict, Any, Optional

from utils.llm_client import LLMClient, LLMError
from config import LLM_CONFIG, INSIGHT_CONFIG

logger = logging.getLogger(__name__)


class InsightLLMEnhancer:
    """将规则引擎的结构化洞察交给 LLM 生成自然语言解读。

    使用方式：
        enhancer = InsightLLMEnhancer(llm_client)
        text = await enhancer.enhance(
            structured_insights=structured,
            question="各部门的日营业额",
            raw_data_summary="门店名称,日营业额(元)\\n外滩店,8900\\n西湖店,3200",
        )

    设计原则：
    1. 规则引擎结果作为唯一事实来源，LLM 不得编造
    2. 提供原始数据摘要供 LLM 参考具体数字
    3. LLM 只负责语言润色和原因推测，不做新的统计分析
    4. 失败时静默降级，返回 None，前端使用规则引擎结果
    """

    # System Prompt — 定义 LLM 角色和行为约束
    SYSTEM_PROMPT = """你是数据分析专家。根据以下结构化分析结果，用通俗易懂的语言为用户解读数据。

你必须严格遵守以下规则：
1. 只能基于给定的结构化分析结果进行解读，不得编造结果中不存在的数据
2. 不得引入结构化结果中未提及的字段名、数值或维度
3. 可以对数据背后的可能原因进行合理推测，但必须标注"推测"
4. 语言要通俗易懂，避免使用专业术语（如"标准差""皮尔逊系数"），用"波动幅度""相关程度"等通俗表达替代
5. 所有数字必须与给定的结构化结果一致，不得四舍五入或近似
6. 不使用 Markdown 标题格式"""

    def __init__(self, llm_client: LLMClient):
        """初始化 LLM 洞察增强器。

        Args:
            llm_client: LLM 客户端实例（03 文档已实现的 LLMClient）
        """
        self.llm = llm_client

    async def enhance(self, structured_insights: Dict[str, Any],
                      question: str, raw_data_summary: str) -> Optional[str]:
        """将结构化洞察增强为自然语言解读。

        将规则引擎的结构化结果 + 原始数据摘要 + 用户问题组装为 Prompt，
        调用 LLM 生成 2-3 段通俗易懂的解读文字。

        Args:
            structured_insights: 规则引擎生成的结构化结果，格式：
                {
                    "summary": "一句话总结",
                    "insights": ["洞察1", "洞察2", ...],
                    "key_findings": [{"type": "ranking", "title": "...", "value": "..."}],
                    "suggestions": ["建议1", "建议2"]
                }
            question: 用户原始问题
            raw_data_summary: 原始数据摘要（前 10 行的文本表示）

        Returns:
            增强后的自然语言洞察文本（2-3 段），失败时返回 None。
            格式示例：
            "从分析结果来看，外滩店的日营业额表现最为突出，达到8,900元，
             显著高于西湖店的3,200元，两者差距约2.78倍。

             推测外滩店的优势可能来自于其所在商圈的人流量更大，
             以及菜品定价较高（蟹粉拌面45元 vs 龙井虾仁饭38元）。

             建议西湖店参考外滩店的畅销菜品结构，优化菜品组合，
             同时关注是否存在运营效率上的差距。"
        """
        # 构建结构化结果的文本表示
        structured_text = self._format_structured_insights(structured_insights)

        # 构建 User Prompt
        user_prompt = self._build_user_prompt(
            structured_text=structured_text,
            question=question,
            raw_data_summary=raw_data_summary,
        )

        try:
            # 调用 LLM（使用解读专用的温度和 token 配置）
            response = await self.llm.generate(
                prompt=user_prompt,
                system_prompt=self.SYSTEM_PROMPT,
                temperature=LLM_CONFIG['temperature_interpretation'],  # 0.3
                max_tokens=LLM_CONFIG['max_tokens_interpretation'],   # 400
            )

            if not response or not response.strip():
                logger.warning('LLM 增强洞察返回空文本')
                return None

            return response.strip()

        except LLMError as e:
            logger.warning(f'LLM 增强洞察调用失败: {e}')
            return None
        except Exception as e:
            logger.warning(f'LLM 增强洞察异常: {e}', exc_info=True)
            return None

    def _format_structured_insights(self, structured: Dict[str, Any]) -> str:
        """将结构化洞察字典格式化为 LLM 易读的文本。

        Args:
            structured: 规则引擎输出的结构化洞察

        Returns:
            格式化后的文本，如：
            "一句话总结：外滩店日营业额最高...
             关键发现：
             1. [排名分析] 排名最高：外滩店...
             2. [异常值检测] 检测到...
             行动建议：
             1. 西湖店排名最低..."
        """
        lines = []

        # 一句话总结
        summary = structured.get('summary', '')
        if summary:
            lines.append(f'一句话总结：{summary}')
            lines.append('')

        # 关键发现
        key_findings = structured.get('key_findings', [])
        if key_findings:
            lines.append('关键发现：')
            for i, finding in enumerate(key_findings, 1):
                ftype = finding.get('type', '')
                title = finding.get('title', '')
                value = finding.get('value', '')
                lines.append(f'{i}. [{title}] {value}')
            lines.append('')

        # 所有洞察
        insights = structured.get('insights', [])
        if insights:
            lines.append('全部洞察：')
            for i, insight in enumerate(insights, 1):
                lines.append(f'{i}. {insight}')
            lines.append('')

        # 行动建议
        suggestions = structured.get('suggestions', [])
        if suggestions:
            lines.append('行动建议：')
            for i, suggestion in enumerate(suggestions, 1):
                lines.append(f'{i}. {suggestion}')

        return '\n'.join(lines)

    def _build_user_prompt(self, structured_text: str, question: str,
                           raw_data_summary: str) -> str:
        """构建 LLM 的 User Prompt。

        Prompt 结构：
        1. 结构化分析结果（事实基础）
        2. 用户原始问题
        3. 原始数据摘要（前 10 行，供参考具体数字）
        4. 输出要求（2-3 段，核心发现 + 原因推测 + 行动建议）

        Args:
            structured_text: 格式化后的结构化洞察文本
            question: 用户原始问题
            raw_data_summary: 原始数据摘要

        Returns:
            完整的 User Prompt 字符串
        """
        prompt = f"""分析结果：
{structured_text}

用户问题：{question}

数据摘要（前{INSIGHT_CONFIG['llm_max_data_rows']}行）：
{raw_data_summary}

请用2-3段话解读数据，包含：
1. 核心发现（最重要的1-2个发现）
2. 数据背后的可能原因
3. 可行的行动建议

要求：语言通俗、避免术语、有具体数字支撑。"""
        return prompt
```
